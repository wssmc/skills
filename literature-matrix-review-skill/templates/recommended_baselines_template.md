# Recommended Baselines

| Baseline | Type | Why include it | Expected implementation difficulty | Notes |
|---|---|---|---|---|
| SPT | Dispatching rule | Simple lower-level baseline | Low | Useful for sanity check |
| LPT | Dispatching rule | Contrasts with SPT | Low | Useful for machine-load-oriented scheduling |
| NEH-like heuristic | Constructive heuristic | Common in flow shop variants | Medium | Can be adapted to TWET |
| IG | Metaheuristic | Closest method family | Medium | Important baseline |
| ILS | Metaheuristic | Strong local search baseline | Medium | Useful for ablation comparison |
| GA | Metaheuristic | Common population-based baseline | Medium | Useful broad comparison |
