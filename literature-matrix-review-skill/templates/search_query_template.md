# 检索式模板

## Problem Type Queries

```text
("{problem_keyword_1}" OR "{problem_keyword_2}" OR "{problem_keyword_3}")
```

## Objective Queries

```text
("{objective_keyword_1}" OR "{objective_keyword_2}" OR "{objective_keyword_3}")
```

## Constraint Queries

```text
("{constraint_keyword_1}" OR "{constraint_keyword_2}" OR "{constraint_keyword_3}")
```

## Method Queries

```text
("{method_keyword_1}" OR "{method_keyword_2}" OR "{method_keyword_3}")
```

## Strong Query

```text
({problem_query}) AND ({objective_query}) AND ({constraint_query})
```

## Medium Query

```text
({problem_query}) AND ({objective_query})
```

## Method Reference Query

```text
({problem_query}) AND ({method_query})
```
