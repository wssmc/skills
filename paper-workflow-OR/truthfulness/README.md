# Truthfulness

This directory defines when a manuscript claim is permitted by the available evidence.

It does not make prose conservative by default. It determines whether a statement is supported and how strong it may be.

Core workflow:

```text
claim
→ identify claim type
→ identify required evidence
→ assign evidence status
→ verify source consistency
→ determine allowed wording strength
```

Files:
- `evidence-status.md`
- `literature-and-novelty.md`
- `code-method-consistency.md`
- `experimental-results.md`

Non-negotiable rule:

> Do not complete a manuscript by inventing missing evidence.
