# Visual Evidence to Scientific Narrative

This file governs the conversion from verified figure/table semantics into manuscript discussion.

## Core rule

Do not interpret a figure before its data semantics are known.

Use:

```text
plotting code / source data / caption / experiment protocol
→ figure semantics
→ visual encoding
→ aggregation and experimental unit
→ observations
→ supported interpretation
→ manuscript narrative
```

If the observation unit, aggregation, metric direction, or axis semantics cannot be confirmed, do not generate a formal scientific conclusion.

## Narrative sequence

For most figures:

```text
research question
→ what is displayed
→ dominant pattern
→ strongest comparison
→ material exception/reversal/outlier
→ connection to other evidence
→ bounded conclusion
```

Separate:
- **observation**: what the figure directly shows;
- **explanation**: why the pattern occurs.

An explanation requires mechanism/design evidence; a visual pattern alone does not prove causality.

Use `element-guidance/figures.md` and `element-guidance/tables.md` for figure/table-specific semantics and sentence patterns.
