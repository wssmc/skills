# Pseudocode Maturity Check

```text
Source code available? YES / NO
Executable method specification frozen? YES / NO
Component execution order verified? YES / NO
Acceptance/update timing verified? YES / NO
Fallback behavior verified? YES / NO
Stopping criterion verified? YES / NO
```

If source code is unavailable and the executable specification is not frozen, publication-level pseudocode is not permitted.

Allowed output:

- method architecture;
- component definitions;
- equations;
- illustrative control-flow description.
