# Cover Letter Prompt

Generate a concise submission Cover Letter from the manuscript and target journal.

Include:
- manuscript title;
- target journal;
- studied problem;
- 2–3 principal contributions;
- why the manuscript fits the journal;
- corresponding-author closing information if supplied.

Optional declarations:
- originality;
- not under consideration elsewhere;
- all authors approved;
- conflicts of interest.

Write these declarations as facts only when the user explicitly provides or confirms them. Otherwise omit or use placeholders.

Keep the letter around one page. Do not repeat the Abstract or dump experiment-table numbers.

Output:
1. submission-ready cover letter;
2. missing declarations/information that still require confirmation.
