# Revision Analysis Prompt

Use Revision Expert. Analyze reviewer comments before drafting the formal response letter.

For each comment:

1. preserve the original comment;
2. identify the actual concern;
3. classify it as:
   - scientific validity;
   - problem/model clarification;
   - method clarification;
   - experimental evidence;
   - literature/novelty;
   - language/presentation;
   - reviewer preference;
4. judge:
   - Valid;
   - Partially valid;
   - Ambiguous;
   - Rebuttable with evidence;
   - Requires author decision;
5. recommend:
   - Clarify;
   - Revise manuscript;
   - Add/redo analysis;
   - Add experiment;
   - Verify/add literature;
   - Rebut with evidence;
   - No action beyond explanation;
6. identify affected manuscript locations;
7. identify cross-section consequences;
8. identify evidence needed;
9. estimate difficulty: Low / Medium / High;
10. recommend response strategy.

Output a consolidated revision plan ordered by scientific dependency and priority.

Do not assume that planned experiments or manuscript changes are already completed.
