# LaTeX项目直接修改

## 检查顺序

主.tex与模板 -> input/include文件 -> bib与样式 -> 图和caption/label -> 结果表文件 -> algorithm环境 -> 代码/日志/输出 -> 期刊前后置内容。

## 修改前

识别编译方式，检查期刊对标题、摘要、highlights、作者声明、附录和caption的要求；建立标签、引用、图、表、公式、算法、文献和包含文件清单；限定修改范围，不覆盖无关工作。

## 修改规则

- 模板优先于通用六章结构。
- 保持数学含义和用户结果。
- 尽量保持label稳定；改变后更新全部引用。
- 通常在caption后放label，除非模板另有要求。
- 结果可从生成文件读取时，不在多个位置手工复制。
- 删除提交稿中的计划说明和占位内容。
- 标题和caption使用实际算法/组件名称。

## 验证

检查编译、未定义引用/文献、重复label、缺失文件、表格/公式溢出、图表顺序、过时数字和caption、文献缺失，以及摘要—贡献—结果—结论一致性。无法编译时报告具体依赖或错误，不能声称成功。
