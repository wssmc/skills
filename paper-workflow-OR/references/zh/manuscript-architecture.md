# 论文整体结构

## 运筹优化论文主线

```text
研究背景
-> 运筹决策或优化问题
-> 研究缺口与技术困难
-> 数学模型
-> 求解方法
-> 计算证据
-> 理论/实践意义与边界
```

## 默认正文结构

1. 引言
2. 文献综述/相关工作
3. 问题描述与数学模型
4. 求解方法
5. 计算实验
6. 结论与未来研究

目标期刊有明确结构要求时，以期刊模板为准。

## 段落规划表达

```text
Guide：要素 -> 要素 -> 要素
段1：本段功能和内容。
段2：本段功能和内容。
```

不再用①②等序号表达章节内容。

## 小标题控制

- 主章节通常设置3—5个小节。
- 不承担独立论证功能的说明内容用段落表达。
- 三级标题仅用于实际算法组件、证据模块或独立文献主题。
- 长证明、低层实现、完整参数表和补充实验按期刊规则移至附录。

## 默认固定证据包

典型“模型—算法—实验”型论文默认规划：文献矩阵、示例数据表和问题特征图、符号表、算法框架图、适用时的参数校准表图、算法比较表、统计表、收敛曲线，以及主要组件对比表图。案例与敏感性/稳健性分析为条件模块。
