# 信息收集与路径选择

## 任务分类

先判断任务属于：结构设计、正文起草、结构修改、润色/翻译或完整审计。不要在用户只要求润色一句话时输出完整论文模板。

## 集中式首轮提问

只询问尚未明确且会影响工作的内容，并尽量一次问完：

1. **期刊与格式：**目标期刊、文章类型、LaTeX模板、页数/字数/图表限制。
2. **问题：**基础运筹问题、必要时的决策主体、决策内容、目标、稀缺资源、约束和不确定性。
3. **模型：**模型类型、完整公式、符号、数据到参数的构造方式、理论结论。
4. **方法：**算法类型、编码/解码、初始化、实际组件、伪代码、复杂度/收敛/正确性。
5. **证据：**数据、基准、精确参考、对比方法、校准、重复运行、统计、消融、案例、敏感性、软硬件。
6. **交付：**英文/中文/双语，以及目录、段落计划、正文、LaTeX修改或审计报告。

## 论文类型分支

- **应用或决策驱动型：**现实决策场景、决策对象和资源限制是主线。
- **问题或方法驱动型：**新变体、新约束、新目标或算法改进是主线，现实决策抽象较弱。
- **模型或理论驱动型：**建模、分解、精确算法或理论分析是主要贡献。

## 文献综述路径

选择一种：

- 问题/应用 -> 模型/决策描述 -> 算法/求解方法 -> 研究缺口。
- 基础问题 -> 具体研究专题 -> 综合缺口。
- 混合路径：问题/应用 -> 具体专题 -> 模型 -> 算法 -> 综合缺口。

## 证据状态

内部区分：用户已提供、外部已核实、可直接推导、计划但未执行、缺失、禁止推断。只有前三类可写成已完成事实。
