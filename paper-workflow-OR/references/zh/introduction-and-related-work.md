# 引言与文献综述

## 1. 引言分支

### 路径A：应用或决策驱动型

**Guide：**应用背景 -> 决策问题抽象 -> 当前实践或研究 -> 研究难点 -> 研究缺口 -> 本文模型与方法 -> 主要贡献 -> 文章结构

按连贯逻辑覆盖这些功能：建立运行需求；把场景抽象为运筹问题（谁决策、决定什么、稀缺资源、约束/不确定性和评价标准）；说明尚未解决的建模或求解困难；定义本文问题与方法；给出有证据边界的贡献；期刊需要时说明文章结构。

段落可按篇幅和论证密度合并或拆分，不要机械地“一项功能一段”。

### 路径B：问题或方法驱动型

**Guide：**基础问题 -> 问题/方法发展 -> 新特征或方法局限 -> 技术难点 -> 研究缺口 -> 本文方法 -> 主要贡献 -> 文章结构

适用于现实决策抽象不强的论文。必须明确基础问题、扩展内容、现有模型或算法不能直接处理的原因，以及本文增加的能力。

### 路径C：模型或理论驱动型

**Guide：**研究领域与基础模型 -> 现有建模范式 -> 表达/理论局限 -> 新计算困难 -> 本文模型/理论/算法 -> 主要贡献 -> 文章结构

适用于建模、分解、精确算法或理论导向论文。

无论选择哪条路径，都要控制宏观背景篇幅，尽快落到精确研究问题。贡献应明确“构建/设计/证明/验证了什么”，不能只列出论文做过的活动。

## 2. 文献综述分支

### 路径A：问题—模型—算法

建议功能：问题与应用研究、模型与决策描述研究、精确/启发式/分解/学习辅助求解研究、综合缺口与本文定位。每条研究线应完成定义、分类、假设/能力/证据比较，并说明它对本文研究问题的具体含义。若某条研究线只是建立基准或说明方法选择，不必强行制造“缺口”。

### 路径B：基础问题—具体专题

围绕基础问题和具有独立文献基础的实际专题组织；若拆分后只会重复相同研究或假设，应合并紧密相关的专题。最终标题必须使用真实专题名称。

### 路径C：混合路径

当论文既包含多个具体问题特征，又有独立模型或算法贡献时，组合问题/应用、具体专题、模型、算法和综合缺口。

## 文献矩阵

当结构化比较比正文更清楚地揭示研究缺口、基准选择或本文定位，而且期刊篇幅允许时使用。编码稀疏、与正文重复或缺少可靠来源时应省略。

`Table X. Comparison of representative related studies and this study.`

可选列：Study、Problem or application setting、Objective、Key problem characteristics、Model or formulation、Solution method、Validation or data。只保留能回答定位问题的列；每个单元格都应可回到原文核验，并使矩阵、正文与贡献声明一致。

## 禁止模式

禁止按作者年份流水账、未经检索的首次声明、最终稿中的“问题线/专题A”等元标题、与后文贡献和证据无对应关系的研究缺口，以及把有限检索中“未发现”当作“不存在既有研究”的证明。
