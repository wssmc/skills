# 引言与文献综述

## 1. 引言分支

### 路径A：应用或决策驱动型

**Guide：**应用背景 -> 决策问题抽象 -> 当前实践或研究 -> 研究难点 -> 研究缺口 -> 本文模型与方法 -> 主要贡献 -> 文章结构

- **段1：**说明应用需求和运行价值；进一步明确谁决策、决定什么、什么资源稀缺、哪些约束或不确定性重要，以及如何评价方案。
- **段2：**说明当前实践和已有研究已经解决什么，以及现有规则、模型或算法的不足。
- **段3：**说明关键特征共同存在时的建模和求解困难，形成具体研究缺口。
- **段4：**定义本文问题，概括模型和方法，并说明它们为何适合该决策环境。
- **段5：**按缺口顺序给出有边界的贡献。
- **段6：**说明章节安排。

### 路径B：问题或方法驱动型

**Guide：**基础问题 -> 问题/方法发展 -> 新特征或方法局限 -> 技术难点 -> 研究缺口 -> 本文方法 -> 主要贡献 -> 文章结构

适用于现实决策抽象不强的论文。必须明确基础问题、扩展内容、现有模型或算法不能直接处理的原因，以及本文增加的能力。

### 路径C：模型或理论驱动型

**Guide：**研究领域与基础模型 -> 现有建模范式 -> 表达/理论局限 -> 新计算困难 -> 本文模型/理论/算法 -> 主要贡献 -> 文章结构

适用于建模、分解、精确算法或理论导向论文。

## 2. 文献综述分支

### 路径A：问题—模型—算法

建议功能：问题与应用研究、模型与决策描述研究、精确/启发式/分解/学习辅助求解研究、综合缺口与本文定位。每条研究线必须完成定义、分类、比较和缺口总结。

### 路径B：基础问题—具体专题

基础问题单列；每个具有独立文献基础的实际研究专题单列。最终标题必须使用真实专题名称。

### 路径C：混合路径

当论文既包含多个具体问题特征，又有独立模型或算法贡献时，组合问题/应用、具体专题、模型、算法和综合缺口。

## 文献矩阵

完整方法型论文默认包含：

`Table X. Comparison of representative related studies and this study.`

可选列：Study、Problem or application setting、Objective、Key problem characteristics、Model or formulation、Solution method、Validation or data。只保留能揭示研究缺口的列，矩阵与正文必须一致。

## 禁止模式

禁止按作者年份流水账、未经检索的首次声明、最终稿中的“问题线/专题A”等元标题，以及与后文贡献和证据无对应关系的研究缺口。
