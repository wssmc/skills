# 问题模型章与求解方法章可选协同规划

只有两章同时在任务范围内且协同能避免公式、符号或职责重复时，才使用本参考。默认交付章节级蓝图，不拆成逐段清单。

对排程启发式/元启发式论文，使用[第3–4章固定英文标题模板](../../templates/chapter3-4-section-template.md)。期刊模板或现有稿件已有标题时，以项目原结构为准。

## 1. 第3章固定结构

章标题使用 `Problem Description and Mathematical Formulation`。

### 3.1 `Problem Description`

按以下顺序写：

1. 排程环境、工件/工序、资源、路线、决策和目标；
2. 明确列出问题实际采用的假设，并说明这些假设限定了什么；
3. 给出一个小型说明性实例，包含输入数据表和由同一数据生成的甘特图/网络图；
4. 解释图中最关键的等待、资源冲突、可行性关系或目标值。

PFSP假设检查项包括：工件可用时刻；加工时间是否确定；机器访问顺序；机器和工件容量限制；是否允许中断；换型与运输时间；缓冲/阻塞和机器可用性；统一排列；目标函数。只写已有材料支持的假设，不能把检查项自动当成事实。

### 3.2 `Notation and Mathematical Formulation`

符号定义、公式和公式解释放在同一节。先按集合/索引、参数、决策或解表示、派生量给出符号表，再按运行顺序写排程递推、可行性和目标。

每组公式固定使用：

```text
运行规则 → 公式 → 逐项解释 → 公式作用 → 与下一组公式的关系
```

标准目标、可行性和评价公式只在第3章定义一次；第4章引用。只有算法特有的解码、修复或增量评价才留在方法章。没有完整模型证据时不得补造MIP。

## 2. 第4章固定结构

章标题使用 `Proposed Solution Method`。

| 编号 | 固定英文标题 | 写作责任 | 必备支撑 |
|---|---|---|---|
| 4.1 | `Overall Framework` | 方法类别、输入输出、模块、状态、信息流、反馈和停止条件 | 总体流程图 |
| 4.2 | `Solution Representation and Decoding` | 编码对象、解码/评价、与第3章可行性和目标的映射 | 必要时用表示/解码示意或短伪代码 |
| 4.3 | `Initialization` | 构造步骤、评价、并列处理和初始状态 | 多步骤时用短伪代码或构造示例 |
| 4.4 | `Neighborhood Structures` | 每个邻域的目的、选取、变换、输出、可行性、评价和搜索尺度 | 多面板邻域操作图 |
| 4.5 | `[Baseline Method] Search Framework` | 算子选择、候选调用、接受/选择、current/reference/best更新、调度/记忆、终止与返回 | 控制公式或局部伪代码 |
| 4.6 | `[Method-Specific Mechanism Name]` | 动机、触发、状态、规则、更新顺序、与4.5的接口、作用与边界；多个实质机制可继续增加小节 | 机制图、状态表或组件伪代码 |
| 4.7 | `Complete Algorithm` | 按真实顺序整合所有已定义组件 | 完整伪代码 |
| 4.8 | `Feasibility and Computational Complexity Analysis` | 可行性保持；初始化、单次迭代和完整算法的时间复杂度；空间复杂度与主导操作 | 定义规模参数并展示推导 |

4.5和4.6不能保留占位标题。对于当前Adaptive SA，使用 `Simulated Annealing Search Framework` 和 `Adaptive Operator Selection`。

## 3. 从论文结构提炼出的约束

- 邻域负责候选生成，主体搜索负责接受与状态推进，必须使用独立标题。
- 标准组件完整但紧凑；问题适配组件和有证据的核心机制获得更多技术篇幅。
- 完整伪代码放在组件定义之后，不能首次引入复杂机制。
- 复杂度分析不是装饰性Big-O：必须计入初始化、评价器、迭代次数和算法特有子过程。
- 有理论结果时可在4.8增加正确性、连通性、终止或界；没有证据时不声称收敛或全局最优。

## 4. 轻量跨章检查

- 第3章的符号、可行性、目标和评价公式与第4章编码/解码一致。
- 第4章不重复标准模型，只补充算法专用表示、构造、邻域、控制、机制和复杂度。
- 目标或可行性冲突必须报告，不能静默统一。

## 5. 交付边界

默认只输出章节规划表和必备表图/算法清单。若本轮只规划第3、4章，不附加调参范围、随机种子、基线、重复次数、硬件、消融或结果等实验信息问题。只有阻断第3、4章真实写作的问题才列为待确认项。
