# Table Description Template

```text
Table X [reports / summarizes / compares] [what is tabulated].

At the aggregate level, [main result].

Among the comparison methods, [strongest comparator and gap].

At group/instance level, [scale pattern / subgroup behavior].

[Material tie/reversal/exception/solver-status limitation.]

[Optional runtime/statistical/exact-status interpretation.]

Overall, the table indicates [bounded conclusion] over [tested scope].
```

Avoid row-by-row narration.
