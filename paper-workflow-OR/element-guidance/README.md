# Element Guidance

This directory defines how scientific manuscript elements should be presented and described.

It does not decide where an element belongs; that is controlled by the Structure Specification.

Files:
- `prose.md`
- `naming.md`
- `figures.md`
- `tables.md`
- `equations-and-notation.md`
- `pseudocode.md`
- `citations.md`
- `numbers-and-statistics.md`

For figures and tables, the central rule is:

```text
understand the scientific semantics first
→ identify what the element directly supports
→ describe the dominant evidence
→ report material exceptions
→ state a bounded conclusion
```
