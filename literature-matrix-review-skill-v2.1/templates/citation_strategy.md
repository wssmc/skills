# Citation Strategy

| Literature type | Role in paper | Suggested placement |
|---|---|---|
| Foundational HFSP papers | Define shop environment, objectives, and algorithm families | Introduction / Related work 2.1 |
| Missing-operation papers | Support skipped-stage modeling and decoding | Related work 2.2 / Problem description |
| Precedence / BOM / assembly papers | Support release relationship and dependency modeling | Related work 2.3 / Model section |
| Sheet metal / nesting papers | Support industrial background and nesting-scheduling coupling | Introduction / Related work 2.4 |
| Batching / lot papers | Support batch or lot formation mechanisms | Related work 2.3 / 2.4 |
| Algorithm papers | Support encoding, decoding, neighborhood, parameter calibration, and baseline selection | Method / Experiments |
| Recent high-quality papers | Support front-line relevance and gap timeliness | Introduction / Related work |
| Low-venue but key papers | Only support source mechanisms or historical lineage | Related work, with limited weight |
