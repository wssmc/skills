# Sensitivity Analysis Plan

## Factors

| Factor | Suggested levels | Expected purpose |
|---|---|---|
| number of stages | 5, 8, 10 | test shop complexity |
| machine number | 2–7 per stage | test capacity tightness |
| missing-operation rate | low / medium / high | test skipped-stage impact |
| precedence density | sparse / medium / dense | test release-dependency impact |
| NEST:LOT ratio | 1:1, 2:1, 3:1 | test object composition |
| predecessors per LOT | 1–5 | test AND-precedence strength |

## Reporting rule

Sensitivity analysis should explain trends only after results are computed.
