# Novelty Claim Map

| Claim ID | Claimed Novelty | Source Location | Claim Type | Affects Code? | Corresponding Component | Verification Source | Status |
|---|---|---|---|---|---|---|---|
| C1 |  | Introduction / Contribution / Related Work / Ablation | problem / encoding / decoder / initialization / neighborhood / search / acceptance / adaptive / experiment | yes / no |  | Method / Algorithm / Figure / Table / Ablation | candidate / verified / rejected |

## Rules

- Introduction and contributions identify candidate novelty only.
- Ablation identifies components the authors considered important enough to test.
- Method, pseudocode, flowchart and equations define how the component works.
- If a claim cannot be mapped to a component, record it as unresolved.
