# Scheduling Paper Reading Guide

For scheduling papers, inspect these sections in order:

1. Introduction / contributions: candidate novelty.
2. Related work: problem gap and algorithm family.
3. Problem description: environment, constraints, objective.
4. Mathematical model: variables and constraints, if any.
5. Proposed algorithm: representation, decoder, operators, loops.
6. Parameter setting: actual parameter values.
7. Experimental design: benchmark, runs, time limit, metrics.
8. Ablation study: components requiring switches.
9. Tables/figures/footnotes: hidden protocol details.

Never implement from contribution statements alone.
