# Third Party Skills 参考

> 本文件定义项目可调用的外部写作 Skill，用于辅助论文写作。

## 写作 Skill

| Skill 名称 | 用途 | 调用方式 |
|-----------|------|---------|
| `academic-writing-skill` | 学术论文写作辅助（引言、相关工作、问题描述初稿） | 在 LaTeX 写作阶段调用 |

## 文献矩阵 Skill

| Skill 名称 | 版本 | 用途 |
|-----------|------|------|
| `literature-matrix-review-skill-v2.1` | v2.1 | 生成两类文献矩阵 |

### 文献矩阵输出要求

#### 类型一：广泛搜索矩阵

- **范围**：现有文献的广泛搜索，覆盖问题领域主要文献
- **关联度等级**：每篇文献标注关联度（高/中/低）
- **组织方式**：按主题分类
- **用途**：引言和相关工作综述，展示研究领域的全貌

#### 类型二：紧密相关矩阵

- **范围**：仅包含与本文问题直接相关的文献
- **对比维度**：问题规模、算法类型、目标函数、约束类型等
- **用途**：可直接转为论文中的**比较表格**（Table），用于对比本文方法与已有方法
- **格式**：可直接转为 LaTeX 表格

## 调用流程

```text
1. 使用 literature-matrix-review-skill-v2.1 生成两类文献矩阵
   → 广泛搜索矩阵（用于引言和相关工作）
   → 紧密相关矩阵（用于比较表格）

2. 调用 academic-writing-skill 生成初稿
   → 引言：基于问题描述 + 广泛搜索矩阵
   → 相关工作：基于广泛搜索矩阵
   → 问题描述：基于 configs/problem_statement.md + configs/constraints_spec.md

3. 人工审阅和修改初稿
   → 补充算法设计、实验分析、结论等章节
   → 将紧密相关矩阵转为论文中的比较表格
```
