# Changelog

## v1.0.0

- Initial release.
- 定义代码阅读辅助流程：判断阅读目标 → 扫描上下文 → 建立临时知识图 → 从大到小解释 → 给出下一步阅读路线。
- 支持 L1–L5 五层解释策略（一句话说明、角色说明、流程说明、关系说明、风险和改动建议）。
- 提供四种回答格式模板（文件解释、不知道怎么问、功能定位、diff 影响分析）。
- 支持用户水平自适应（初学者 / 有经验工程师 / PM 非技术角色）。
- 定义模糊问题处理策略：复述可能意图 → 主动提出阅读入口 → 改写成清晰问题。
- 提供 `examples/` 示例提示词目录。
