# 示例提示词

## 1. 不知道怎么问

```text
我不知道该怎么问，但我想理解这个模块。请启用代码阅读助手，先帮我判断我可能想问什么，再建立临时阅读地图。
```

## 2. 读一个文件

```text
请用代码阅读助手解释 `src/auth/login.ts`。不要逐行解释，先说明它在项目里的角色、关键函数、调用关系和我应该先看懂的部分。
```

## 3. 找功能实现

```text
请帮我找“用户登录”功能在哪里实现。按入口、路由、service、数据层、测试的顺序找，并输出调用链。
```

## 4. 追踪数据流

```text
请追踪 `userId` 从哪里来、在哪里被校验、在哪里被写入或传递给下游。
```

## 5. 分析改动影响

```text
这是我的 diff。请启用代码阅读助手，分析直接影响、间接影响、风险点和应该补哪些测试。
```

## 6. 给新人导览

```text
请把这个项目按新人 onboarding 的方式讲一遍：先读哪些文件，每个模块负责什么，理解顺序是什么。
```
