# 问题澄清题库

## A. 问题类型

1. 这是 HFSP / HFFS 吗？所有工件是否都按相同阶段顺序加工？
2. 每个阶段是否存在多台并行机器？
3. 工件是否可以跳过某些阶段？
4. 同一阶段内机器是否等效？加工时间是否与机器有关？

## B. 时间与数据

1. 加工时间是否为 `JobID × Stage` 表？
2. 是否有释放时间 release time？
3. 是否有交期 due date 或交期窗口 due window？
4. 是否存在机器不可用时间段 MUPs？
5. 是否存在 setup / transport / waiting / blocking？

## C. 目标函数

1. 优化 makespan 还是 tardiness？
2. 是否考虑 earliness 和 tardiness？
3. 是否是 TWET？权重如何给出？
4. 是否多目标？目标之间如何加权？

## D. 资源约束

1. 是否有运输设备资源？
2. 是否有工人技能或人力容量？
3. 是否有共享窗口或共享资源？
4. 是否有机器维护窗口或不可用期？

## E. 算法与实验

1. 是否需要 CPLEX 求解 MIP？
2. 是否需要 baseline？
3. 是否已有本文算法方向？
4. 是否需要 small / large 数据生成？
5. 是否需要甘特图和收敛曲线？
