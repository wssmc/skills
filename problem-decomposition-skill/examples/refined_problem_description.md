# Refined Problem Description Example

本研究关注带交期窗口、优先工件、共享窗口和机器不可用期的混合流水车间调度问题。系统包含若干工件和多个加工阶段，所有工件按照相同阶段顺序依次加工，每个阶段配置若干台并行机器。工件在阶段上的加工时间由 `processing_times.txt` 中的 `JobID × Stage` 表给出。

需要决定每个工件在各阶段的机器分配、阶段内排序、开始时间和完工时间。模型需满足阶段先后顺序、机器容量、释放时间、交期窗口、优先工件、共享窗口和机器不可用期等约束。目标函数为最小化总加权提前/延期惩罚 TWET。

主体数据采用 txt 文件保存，`index.json` 仅用于串联数据文件和记录配置。后续研究需要检索相似文献并构建问题特征表和方法矩阵表，同时生成 CPLEX/docplex MIP、编码解码、baseline、本文算法、对比实验和甘特图可视化。
